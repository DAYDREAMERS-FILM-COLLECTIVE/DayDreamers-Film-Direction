# Diagram Design Rule

Always use the **Diagram Design** system (`diagram-design` skill / editorial SVG/HTML diagrams) instead of Mermaid diagrams in all sessions, chats, artifacts, and documentation.

## Guidelines:
1. **Never use Mermaid diagrams** (` ```mermaid ` blocks).
2. Use editorial HTML + SVG following the `diagram-design` principles:
   - Self-contained SVG/HTML or embedded SVG diagrams.
   - Clean editorial typography (Geist Sans, Geist Mono, Instrument Serif).
   - No gratuitous shadows or rounded-2xl boxes.
   - Restrained color palette with semantic roles (`paper`, `ink`, `muted`, `accent-tint`, `accent`).
   - Accent color reserved for 1–2 focal elements maximum.
   - Clear visual hierarchy and connector lines with masking.
